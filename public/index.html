The Facebook Page (and Instagram account) each ad account publishes from.

No Page yet? You can still continue: the ads will be prepared as Ads Manager drafts (an import file), and you pick the Page in Ads Manager before publishing.
To publish directly from here later, give your token access to the Page:
  1. Business Settings → Accounts → Pages: the Page must be in your business (add it, or ask the client to share it as a partner).
  2. Business Settings → Users → System users → your system user → Assign assets → Pages → tick the Page → turn on Create ads (or full control).
  3. The token needs pages_show_list, pages_read_engagement and pages_manage_ads. If it was made without them, generate a new token with them ticked and update .env.
  4. Reload this page.
For Instagram: link the Instagram account to the Page (Page settings → Linked accounts), and assign it to the system user under Accounts → Instagram accounts.
